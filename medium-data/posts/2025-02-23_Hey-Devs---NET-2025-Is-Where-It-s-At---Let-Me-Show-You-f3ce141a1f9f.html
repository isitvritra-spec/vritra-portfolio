✨ Simple .NET 9 API to Kick Things Off

Let’s start small. Here’s a .NET 9 minimal API I whipped up for a proof-of-concept last month. It’s a taste of what’s ahead — clean, fast, and cloud-ready.

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.MapGet("/hello", () => "Hello, .NET 9!")
   .WithName("GetHello")
   .WithOpenApi();

app.Run();

Save this as Program.cs , run dotnet new web -o HelloDotNet9, and replace the default code. Hit dotnet run, then browse to http://localhost:5000/hello. You’ll see “Hello, .NET 9!” — a tiny app,

but it’s the seed of something bigger. We’ll build on this later!

✨Example, Cloud-Native Microservice

Here’s a slice of that logistics system I built — a .NET 9 microservice for order processing, wired to Azure Service Bus.

using Azure.Messaging.ServiceBus;
using Microsoft.AspNetCore.Mvc;

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddSingleton(new ServiceBusClient(builder.Configuration["ServiceBusConnection"]));
var app = builder.Build();

app.MapPost("/orders", async ([FromBody] Order order, ServiceBusClient client) =>
{
    var sender = client.CreateSender("order-queue");
    var message = new ServiceBusMessage($"New order: {order.Id}");
    await sender.SendMessageAsync(message);
    return Results.Ok($"Order {order.Id} queued");
});

app.Run();

record Order(int Id, string Customer);

Add this to a .NET 9 project, configure your appsettings.json with a Service Bus connection string, and run it.

Post { “Id”: 1, “Customer”: “Jane” } → to /orders, and it queues the order.

This is the backbone of a scalable system — small, but mighty.

⚫AI and .NET: Intelligence Made Simple

AI’s inescapable in 2025, and ML.NET 3.0 delivers. I built a sentiment analysis tool for a SaaS client’s support portal — 45K+ chat logs, one day to deploy.

Positive chats got auto-replies …. -> negative ones flagged agents… →Satisfaction rose 15%.

Here’s the core of it:

using Microsoft.ML;
using Microsoft.ML.Data;

var context = new MLContext();
var data = context.Data.LoadFromTextFile<ChatData>("chats.csv", hasHeader: true);
var pipeline = context.Transforms.Text.FeaturizeText("Features", nameof(ChatData.Text))
    .Append(context.BinaryClassification.Trainers.SdcaLogisticRegression());
var model = pipeline.Fit(data);
var predictionEngine = context.Model.CreatePredictionEngine<ChatData, ChatPrediction>(model);

var chat = new ChatData { Text = "Love this app!" };
var result = predictionEngine.Predict(chat);
Console.WriteLine(result.Prediction ? "Positive" : "Negative");

public class ChatData
{
    public string Text { get; set; }
    [LoadColumn(1)] public bool Label { get; set; }
}

public class ChatPrediction
{
    [ColumnName("PredictedLabel")] public bool Prediction { get; set; }
}

Train this on a CSV (e.g., text,label rows), and it’s ready to classify. Integrate it into an API, and you’ve got AI in your .NET app.

✨Example Blazor Frontend

Here’s a quick Blazor component to pair with the microservice:

@page "/orders"
@inject HttpClient Http

<h3>Orders</h3>
@if (orders == null)
{
    <p>Loading...</p>
}
else
{
    <ul>
        @foreach (var order in orders)
        {
            <li>@order.Customer - @order.Id</li>
        }
    </ul>
}

@code {
    private Order[]? orders;

    protected override async Task OnInitializedAsync()
    {
        orders = await Http.GetFromJsonAsync<Order[]>("http://localhost:5000/orders");
    }

    public class Order
    {
        public int Id { get; set; }
        public string Customer { get; set; }
    }
}

Run this with the API, and you’ve got a full-stack .NET app. The future’s yours pal!
